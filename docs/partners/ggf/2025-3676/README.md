# ALMA — public record for GGF grant 2025-3676

This directory is a publication-safe record of the work initiated with a
USD 7,000 grant approved by Global Greengrants Fund on 6 June 2025.

The grant helped Yernar Sailybayev move ALMA from a concept to its first working
implementation. The work connected public information about the Almaty orchards
with field observation, geographic context and a controlled route from evidence
to a draft request for verification.

The grant did not finance every later component of ALMA or the whole OASIS
system. Development continued through substantial additional work and resources
contributed by the author. The GGF grant is therefore described as the initial
catalyst, not as payment for the complete present system.
